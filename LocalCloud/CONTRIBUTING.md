# Contributing

Read LICENSE before modifying or publishing this source. Platform forks and
pull requests to the original project are allowed with the original notices.
Use a separate test library, never production settings or media. Explain the
user-visible change, reproduction steps and appropriate checks in a PR.
Do not add AI integrations or external runtime dependencies without an explicit
project decision. Preserve originals and make physical file changes reviewable.

Build with scripts/build.ps1. Keep README.md/README.ru.md and versions consistent.
Do not commit node_modules, binaries, artifacts, logs, databases, secrets or
personal fixtures. Contributions must be yours to submit; disclose AI assistance.
