# Release build

## Windows

Install .NET SDK 10, Node.js 22.12+/24, Python 3 and NSIS 3. Add `makensis.exe`
to PATH or pass its full path with `scripts/package.ps1 -NsisPath`.
The Node lockfile is committed. VERSION is 1.0.0; database schema is 4.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
```

This runs npm ci, frontend build, solution build and core checks, publishes the
Windows x64 server/desktop/updater with self-contained .NET 10.0.12, writes
SHA-256 manifests, builds the NSIS installer and writes release checksums.
No user's storage or config is read during packaging. FFmpeg is excluded from
release binaries and downloaded directly upstream only when Setup's option is
selected. WebView2 download is separately selected and signature-checked.

To create a small delta against an official previous installation manifest:

```powershell
python scripts/release-artifacts.py --delta-baseline PATH_TO_PREVIOUS_RELEASE_JSON
```

The installed baseline must match every omitted file's SHA-256. A full checked
update contains all application files when no baseline is supplied.

## Linux build environment

Server/core checks can run on Linux; Windows projects use EnableWindowsTargeting.
A Linux `makensis` compiler can generate the Windows installer. Linux compilation
does not execute Windows installer/tray behavior.

Native smoke checks are documented in QA-public-1.0.md. Historical QA reports
refer to development numbering and are not proof of physical Windows execution.

## API and browser checks

Use an isolated test library generated by `python tests/generate-public10-assets.py`
(Python Pillow and FFmpeg required). Build the solution and frontend first, then
run `python tests/public10-api.py` and `node tests/public10-ui.mjs` sequentially.
Install Playwright Chromium via `npx playwright install chromium` in the web
folder or set LOCALCLOUD_CHROMIUM to a compatible local binary.

`upgrade14-to-public10.py` additionally needs a real previous 1.4.0 Linux server
publish in artifacts/previous14/server plus current artifacts/linux and
artifacts/updater-linux publishes. It operates only on an isolated temporary
installation/library and verifies data preservation, resumable uploads, rollback
and refusal of an already-public version downgrade. This harness requires Linux,
Python Pillow and FFmpeg; Windows installer execution is a separate smoke test.
