# Security

LocalCloud is intended for trusted private networks, not direct public exposure.
Use the latest official release, enable appropriate access protection, and keep
independent backups. HTTP does not encrypt PIN or file transfers.

Do not post an exploitable issue with private files, tokens, PINs or a database
in a public issue. Use the original author's private contact mechanism if one
is available on the actual repository; no contact address is invented here.
If none exists, request a private reporting route without publishing the exploit.

Third-party runtime/media components have their own update and license policies.
